# Agents — overlay

Add your project-specific specialist agents here. One file per specialty.

Copy and rename `fullstack-specialist.md` as a starting point. Remove this file when you have real specialist files.

The ticket router reads `profile.json` → `specialists[]` to pick which agents to load — keep names consistent.

`script-engineer.md` is not a project specialist: it is core. It creates and updates `.ps1`/`.py` scripts to the standards in [../skills/script-authoring/SKILL.md](../skills/script-authoring/SKILL.md). Keep it.
