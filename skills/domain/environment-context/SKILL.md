# Environment context

Read `profile.json` `integrations` and match a card under `environments/`. Always consider
[../../../environments/local-dev.md](../../../environments/local-dev.md).

Cards store ports, start commands, first search targets, test scope, and gotchas. Do **not** store
ticket-specific findings here — those go to the plan or closeout index.

If the matching card is still a stub, treat `/onboard` as unfinished: fill the card, then continue.
