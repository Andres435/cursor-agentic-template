# Start Ticket

Start a ticket from the project's ticket system (`/start-ticket <TICKET-ID> bug|feature|spike|refactor [--worktree]`): classify it into a work manifest, set up branches (or per-ticket worktrees), plan, and in branch mode build it in the same chat.

Read and execute [playbooks/start-ticket.md](playbooks/start-ticket.md) now. Do not ask for confirmation before reading the playbook.
